# Chapterize Product Register

## Product

Chapterize is a Zotero desktop plugin for previewing, refining, and splitting a
book-length PDF into Zotero book-section items by bookmark or page range.

## Primary Users

- Researchers and students working with edited volumes and handbooks
- Librarians and knowledge workers organizing large PDF collections
- Zotero users who need repeatable chapter extraction without leaving their
  library workflow

## Core Purpose

Turn a PDF outline into a trustworthy split plan, let the user verify physical
and printed page semantics, and create correctly linked Zotero items without
silent omissions or accidental duplicates.

## Brand Personality

Precise, calm, trustworthy, and work-focused. The interface should feel like a
native professional Zotero tool: dense enough for repeated use, but easy to
scan and correct.

## Anti-References

- Marketing-style hero layouts or decorative card grids
- Gradients, ornamental imagery, and saturated color washes
- Hidden automation that changes page ranges without visible feedback
- Oversized typography or excessive whitespace that reduces table utility

## Design Principles

1. Make page-number semantics explicit.
2. Verify the complete split plan before writing files or Zotero items.
3. Keep bulk selection and correction fast for long tables.
4. Preserve user control and surface omissions, overlaps, and duplicates.
5. Fail visibly with actionable recovery information.

## Visual Direction

Use a restrained blue product palette. Blue is reserved for the primary action,
current selection, keyboard focus, and informational states. Neutral surfaces
carry the table structure; red is reserved for validation errors. Avoid relying
on color alone for status.

## Accessibility And Inclusion

- Target WCAG AA contrast for text and controls.
- Preserve logical keyboard navigation and visible focus indicators.
- Pair color with text labels for status and errors.
- Respect reduced-motion preferences.
- Support long English and Chinese labels without clipping or overlap.
